# Electron 侧栏折叠范围规格

## 行为矩阵

| 环境            | collapsed | 主会话列 | 二级菜单列   | Logo 区    |
| --------------- | --------- | -------- | ------------ | ---------- |
| Electron 沉浸式 | false     | 显示     | 按业务域显示 | 显示       |
| Electron 沉浸式 | true      | 显示     | 隐藏         | 显示       |
| 浏览器          | false     | 显示     | 按业务域显示 | 显示       |
| 浏览器          | true      | 隐藏     | 隐藏         | 随主列隐藏 |

## 约束

- 继续使用 `toggle-second-menu` 和 `secondMenuCollapsed` 协议，不修改主进程桥。
- Electron 顶部工具栏仍是沉浸式环境唯一折叠触发入口。
- 折叠后工具栏图标必须切换为展开态，重新点击可恢复二级菜单。
